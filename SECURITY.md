# Security Policy

## Supported versions

Only the latest commit on `main` is supported.

## Reporting

Report vulnerabilities privately through GitHub Security Advisories on this repository. Do not open a public issue for an unauthenticated remote-browser exposure.

## Deployment note

This project is a reference implementation. It has no authentication, session ownership, target URL allowlist, or resource quotas. Do not expose it directly to the public internet.
